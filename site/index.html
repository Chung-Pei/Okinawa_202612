把旅程放到主畫面

iPhone / iPad
  1. 用 Safari 開啟 GitHub Pages 網址。
  2. 點底部「分享」圖示。
  3. 選「加入主畫面」，再按加入。
Android
  1. 用 Chrome 開啟 GitHub Pages 網址。
  2. 點選「安裝應用程式」或瀏覽器選單的「加到主畫面」。
  3. 確認安裝；之後可從主畫面離線開啟已快取內容。

互動地圖底圖、Google Maps 導航與天氣需要網路；離線時仍可查看已載入的行程、住宿聯絡與路段估算。
